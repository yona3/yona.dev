## サイトについて

大学生のときに作って放置していたら、いつの間にか 5 年生になっていました。更新するだけだとつまらないので、Codex（Claude Code）でガシガシ作り直しています 🚧

## AI Agent と作ること

GPT-5.5 がリリースされてから、Codex App との組み合わせが最高です。Claude Code をメインで使ってきましたが、デザイン実装以外であまり優位性を感じなくなってきた（Claude のモデルはあまり指示を守らない）ので、しばらくは Codex メインになりそうです。AskUserQuestion 的なツールが plan mode でしか使えないこと、Codex アプリの電力消費が激しいことはちょっと不満ですが。

今はハーネスエンジニアリングの文脈で ExecPlan ベースの開発を進めていて、とてもいい感じに回っています。このサイトもそのやり方で作りました。まだ課題はあるけど、自動化のレベルは今後もっと高めていきたいです。

## ハリネズミ

Home の見出しの隣にハリネズミ 🦔 が一匹住んでいます。クリックすると走り出し、触れるとふるふる揺れます。サイトの中で一番こだわったところです ☕
