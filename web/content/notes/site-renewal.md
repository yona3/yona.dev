ひとまず公開できる形にしました 🚧。整った記事だけでなく、まとまる前のメモや作業の記録も同じ場所に置けるよう、Notes として日付順に並べる構成に切り替えています。普段着のままで書ける場所にしたい、というのが今回の出発点でした。

## なぜリニューアルしたか

ブログとして整えれば整えるほど、自分から距離が遠くなる感覚がありました。プロフィール写真、強い見出し、最新記事のカード。情報量が増えるほど、書き始めるハードルが上がっていく。

今回は逆方向に振って、罫線と余白だけで構造をつくり、文章と日付を主役にしました。ハリネズミ 🦔 が一匹だけ机の上にいる、そういう景色を目指しています。

## これからの管理について

しばらくは少しずつ書き留める場所を整え、内容を充実させていきます。将来的には Notion を執筆元として使い、build 前に repo の Markdown を生成する仕組みを試したいと思っています ✍️。Notion MCP 経由で同期し、CMS 代わりにする方針です。

公開 runtime は `web/content/notes/*.md` の直読を維持し、Notion token などの secret は client や log に出さない契約に揃えます。

## 今ある場所

- Home: 挨拶とサイトの入口
- About: このサイトについて
- Notes: 文章と記録の置き場

これから少しずつ、書きたいことを書いていきます ☕。
