# 古い本屋のようなサイトについて

白くて、少しだけ黄ばんでいて、余白がある。たくさんのものが置かれているのに、不思議と急かされない場所がある。

サイトもそういう場所にできるといい。情報を速く消費するためではなく、少し立ち止まって読める場所。

- 写真には頼りすぎない
- 文字と余白で温度を作る
- 遊び心は、見つけた人だけが気づくくらいでいい
