個人サイトを作り直すたびに、つい外向けに振ってしまう癖がある。プロフィール画像、強い見出し、最新記事のカード。情報量を増やすほど、自分から距離が遠くなっていく感覚があった。

今回は逆方向に振ってみた。背景は白に少しだけ黄色を混ぜ、本文は明朝、写真は使わない。記事と日々のメモを分けず、Notes として日付順に並べる。種類ラベルは小さく添える程度に留める。

参考にしたのは、古い本屋の棚の間にある小さな作業机のような景色だった。情報を速く消費するためではなく、座って読み、書き留めるための場所。実績を売り込むより、何を面白がっているかが伝わる場所にしたい。

## 何を捨てたか

最初の draft では、Hero に大きな見出しを置き、Notes の上にカテゴリーフィルターを並べていた。一度書いてから眺めて、結局すべて削った。

- プロフィール写真と強いビジュアル
- カードレイアウトと境界の影
- カテゴリーフィルターと記事タイプ別の見出し
- 「最新」「人気」「おすすめ」のラベル

代わりに残ったのは、日付・種別・タイトルだけが並ぶ静かなリストと、本文を中心に据えた余白だった。捨てる作業のほうが、足す作業より時間がかかった。

## 質感の調整

色は少なくする。背景はほぼ白だが純白にはせず、少しだけ古い紙の黄ばみを混ぜている。

```css
:root {
  --color-background: #fcf8f0;
  --color-primary: #2c261f;
  --color-link: #6c4d35;
}
```

リンクは青を避けて、赤茶を使った。ボタン化はしない。下線は細く、hover で薄い罫が点く程度。境界は線か余白のどちらかに寄せて、両方は使わない。

### 線をどこまで残すか

最初は note 一覧の各行と、Hero と Notes の境目にも罫を入れていた。並べてみると、線が増えるたびに「部品感」が強くなった。Notes の罫だけを残し、それ以外は余白で終わらせるようにした。

カードを使わないと、要素同士のグルーピングが曖昧になりやすい。それを罫で補強したくなる気持ちと、紙のような静けさを保ちたい気持ちの綱引きが、しばらく続いた。

## これから

文章を増やすより、書きやすい場所を整えるほうを先にやった。次は中身を、徐々に書きながらの形に寄せていく。
