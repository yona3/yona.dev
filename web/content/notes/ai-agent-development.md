# AI Agent と開発するということ

AI Agent と開発することは、単に手を速くすることではない。考えを外に置き、もう一度読み直し、別の角度から検討するための作業環境を作ることに近い。

コードを書く速度よりも、判断の粒度が変わることのほうが面白い。何を任せ、何を自分で決めるか。どこまでを機械的に進め、どこからを感覚として残すか。

このサイトも、その実験のひとつとして育てていく。
