# ExecPlan 履歴

この directory は旧 ExecPlan の履歴置き場です。現在の計画や完了判定の正本ではありません。

## 現在の正本

- 設計: `docs/superpowers/specs/`
- 実装計画: `docs/superpowers/plans/`
- 開発フロー: `AGENTS.md` の `Superpowers`
- 履歴案内: `PLANS.md`

## 履歴 directory

- `completed/`: 完了済みとして保存された旧 ExecPlan。
- `archived-active/`: Superpowers 移行時点で `active/` に残っていた旧 ExecPlan。
- `active/`: 旧互換の空 directory。新規作業では使わない。

旧 ExecPlan 本文は作成時点の判断ログとして扱い、現在の schema や文体に合わせて書き換えません。
